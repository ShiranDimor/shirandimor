# NQ Daily Levels – 50% / Asia / London

אינדיקטור אחד ל-TradingView (Pine Script v6) עם חמישה קווים:
50% Daily Range, Asia High, Asia Low, London High, London Low.
כל השעות לפי שעון ניו יורק (כולל שעון קיץ/חורף), גם אם הגרף מוצג בשעון ישראל.

## התקנה
1. פתחי ב-TradingView גרף של NQ או MNQ (`NQ1!`, `MNQ1!` או חוזה ספציפי).
2. **Pine Editor** (למטה) → **Open** → **New blank indicator**.
3. מחקי את כל מה שכתוב שם, הדביקי את כל התוכן של `nq-daily-levels.pine` → **Save** → **Add to chart**.
4. מסחר דרך Tradovate: **Trading Panel** בתחתית הגרף → **Tradovate** → התחברות.

## הגדרות (גלגל השיניים ליד שם האינדיקטור)
- שעת תחילת יום המסחר (ברירת מחדל 18:00).
- חלון אסיה (20:00–00:00) וחלון לונדון (02:00–05:00), כולם בשעון ניו יורק.
- לכל קבוצה: הצגה/הסתרה, צבע, עובי וסגנון.
- תוויות: הצגה, מרחק מהנר האחרון, צבע טקסט, גודל, ומחירים על סקאלת המחירים.

## הערות
- מומלץ טווח זמן של דקה ומעלה. בגרף שניות ייתכן שלא נטענה היסטוריה מספיקה, ואז התווית תציג `(partial)`.
- NQ ו-MNQ הם גרפים נפרדים, ולכן ייתכן הבדל קטן במחירים ביניהם.
