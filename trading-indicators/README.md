# 50% Daily Range – NQ / MNQ

אינדיקטור ל-TradingView (Pine Script v6) שמסמן קו אופקי ב-50% מהטווח היומי:
`(גבוה יומי + נמוך יומי) ÷ 2`, מתחילת יום המסחר ב-18:00 שעון ניו יורק.

## התקנה (TradingView, גם כשהחשבון ב-Tradovate)
1. פתחי גרף של NQ או MNQ ב-TradingView (למשל `NQ1!` / `MNQ1!` או חוזה ספציפי כמו `NQZ2026`).
2. בתחתית המסך: **Pine Editor** → **Open** → **New blank indicator**.
3. מחקי את כל מה שיש שם, והדביקי את כל התוכן של `50-percent-daily-range.pine`.
4. **Save** (שם: 50% Daily Range) → **Add to chart**.
5. חיבור ל-Tradovate: בפאנל **Trading Panel** בתחתית הגרף בחרי **Tradovate** והתחברי. אפשר לסחור ישירות מהגרף עם הקו.

## הגדרות (גלגל השיניים ליד שם האינדיקטור)
- **צבע / עובי / סגנון** (Solid, Dashed, Dotted) של הקו.
- הצגת התווית, המרחק שלה מהנר האחרון, צבע הטקסט והגודל.
- הצגת המחיר על סקאלת המחירים.

## הערות
- עובד בכל טווח זמן מיומי ומטה, ומציג את אותו מחיר בכולם.
- NQ ו-MNQ הם גרפים נפרדים, ולכן ייתכן הבדל קטן במחיר ביניהם. הקו מחושב לפי החוזה שבגרף.
- בין 17:00 ל-18:00 (הפסקת המסחר) ובסופ"ש מוצג הקו של יום המסחר האחרון.
