# תוכן יומי לסושיאל של שירן

כלים לבניית התוכן היומי (אינסטגרם + פייסבוק). המשימה המתוזמנת "תוכן יומי" מריצה את זה כל בוקר מסחר.

- `design.py`: מערכת העיצוב (frame/story/head/para/mark/n/big/row). הכללים הקשיחים כתובים בראש הקובץ.
- `chart.py`: גרף נרות כ-SVG שנכנס ישר לתוך `slides_html`.

## איך מכניסים פוסט ללוח האישורים

1. בונים רשימת פוסטים כ-JSON, כל פוסט עם השדות: `content_type` ('story' / 'feed_post'), `topic`, `hook`, `caption`, `hashtags`, `slides_html` (מערך של מסמכי HTML), `scheduled_at` (UTC), `cta_path`.
2. אין גישת רשת מהקונטיינר, ולכן מעבירים את הקובץ דרך GitHub: דוחפים לענף `tmp-social-pack` (לא ל-main).
3. ב-Supabase (פרויקט vpkujbccfqevylsdpbyh) מריצים:
   `select net.http_get('https://raw.githubusercontent.com/ShiranDimor/shirandimor/<sha>/<path>')`
   ואחר כך, בשאילתה נפרדת, מכניסים כ-`status='draft'` מתוך `net._http_response`:
   - `platform='both'`
   - לעמודות `hashtags` ו-`caption` צריך coalesce, כי הן NOT NULL
4. כדי שהתמונות יירנדרו מיד, מפעילים את הקרון (בקריאה נפרדת):
   `do $$ begin execute (select command from cron.job where jobname = 'publish-scheduled-marketing'); end $$;`
   - להפעיל פעם אחת בלבד. יש נעילה, אבל בכל זאת לא להפעיל ברצף.
5. שירן מאשרת בעצמה בלוח הבקרה, בטאב "ממתינים". **אף פעם לא מאשרים במקומה.**

## נתוני מחירים

את הנתונים מושכים דרך Supabase:
`net.http_get('https://query1.finance.yahoo.com/v8/finance/chart/<SYM>?range=1y&interval=1wk')`

- למדדים: `^GSPC`, `^IXIC`, `^VIX`, `QQQ`, `SPY`.
- את ה-content שומרים לקובץ ופותחים עם `chart.load_yahoo()`.
- אפשר לקצר את ה-JSON כבר ב-SQL: עיגול ל-2 ספרות, ורק השדות timestamp/open/high/low/close.
- הנר האחרון יכול להיות חלקי או כפול. בודקים את התאריכים שלו.

## הקול והכללים (לא נתון למשא ומתן)

- **גוף ראשון בלבד, בקול של שירן.** אנטי-הייפ, שקיפות, ניהול סיכונים.
- **אסור להמליץ.** בלי "תקנו" ובלי "תמכרו". מנסחים כמו "מה אני רואה ולמה אני מחכה", ובכיתוב של כל ניתוח מוסיפים: "זו לא המלצה. ככה אני מסתכלת על זה".
- **לא חוזרים על אותו מסר** באותו יום או ביום שאחריו. לפני הכנסת פוסט בודקים מה כבר מתוזמן.
- **בסופ״ש כותבים "סופ״ש שקט ורגוע"**, אף פעם לא "שבת שלום". בשבת לא מתזמנים לפני צאת השבת.
- **סיום הכיתוב בפיד:** `CTA_END` ("כנסו ללינק 👇🏿 / Shirandimor.com").
- **עובדות רק ממקורות**, שנבדקו באותו בוקר. אם יש ספק, לא כותבים.
- **משפטים שלה שאפשר לשלב, במינון:**
  - "לא קונים כותרות - סוחרים את הגרף"
  - "סטופ זה קודש"
  - "בוחרים עסקאות בפינצטה"
  - "שוק ההון הרבה יותר פשוט ממה שעושים ממנו"
  - "מנטלי זה הכול"
  - "לא צריך לדעת הכול. צריך לדעת מה לעשות"
- **אחרי בנייה:** מרנדרים לתמונות (playwright) ובודקים בעין לפני ההכנסה. מחפשים מספרים ששבורים בין שורות, טקסט חתוך, וריבועים במקום תווים.
